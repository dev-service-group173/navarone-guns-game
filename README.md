# ⚓ The Allies & The Attack on Navarone Guns

A World War II naval and coastal defense game built with **Phaser 3** and pure **JavaScript**. The project features procedural graphics and Web Audio API synthesizer effects, eliminating the need for external media assets.

## Key Features
* **Dynamic Coastal Guns:** Auto-calculates aiming angles for AA and Naval guns toward moving targets.
* **Retractable Bunker System:** Smooth tween animations to pull guns into caves for protection.
* **Procedural Graphics:** Terrain, ships, planes, and turrets rendered via Phaser Graphics.
* **Procedural Web Audio:** Real-time synthesis for flak cannon fire and explosions.
* **Arcade Physics:** Interactive missile collisions, plane spawns, and spark particle effects.

## How to Run
1. Clone the repository:
   git clone https://github.com/your-username/navarone-guns-game.git

2. Open index.html using a local web server (e.g., VS Code Live Server) to allow Web Audio playback.

## Tech Stack
* JavaScript (ES6+)
* Phaser 3 Engine
* HTML5 Canvas & Web Audio API
